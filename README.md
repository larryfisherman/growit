# growIt

A gym tracker: build training plans (plans -> days -> exercises), start a workout from a
plan day or from scratch, and log sets. The mobile app works offline first: every write
is queued on the device and replayed when the API is reachable again.

- **Backend:** .NET 10, ASP.NET Core controllers, Clean Architecture + CQRS (MediatR),
  FluentValidation, EF Core on PostgreSQL. Auth is Cognito access tokens (JWT bearer).
  Runs under Kestrel locally and on AWS Lambda in production.
- **Mobile:** Expo / React Native + TypeScript, TanStack Query, NativeWind, API client
  generated by orval from the backend's OpenAPI spec.

## Running locally

Prerequisites: .NET 10 SDK, Docker, Node with pnpm.

1. **Database**

   ```sh
   docker compose up -d db
   ```

2. **API** (applies pending EF migrations on startup, listens on port 5053)

   ```sh
   dotnet run --project src/GrowIt.API
   ```

   In Development the OpenAPI spec is served at `/openapi/v1.json` and the Scalar UI at
   `/scalar`. `/health` answers without auth. The connection string and the Cognito
   `Authority` / `ClientId` come from `src/GrowIt.API/appsettings.json`.

3. **Mobile**

   ```sh
   cd mobile
   pnpm install
   cp .env.example .env      # fill in the EXPO_PUBLIC_COGNITO_* values
   pnpm dev
   ```

   With `EXPO_PUBLIC_API_URL` empty the app targets the local API (the Expo dev server's
   LAN IP on a device, `localhost` on web). `pnpm dev:prod` points it at the production URL.

### After changing the backend contract

Any change to routes or DTOs must be followed by regenerating the mobile client, with the
API running locally in Development:

```sh
cd mobile && pnpm api:gen && pnpm typecheck
```

The offline mutation registry (`mobile/src/offline/mutationDefaults.ts`) is built from
orval's factories, so a contract change shows up there as a type error.

### Database migrations

```sh
dotnet tool restore
dotnet ef migrations add <Name> --project src/GrowIt.Infrastructure --startup-project src/GrowIt.API
```

## Testing

```sh
dotnet build GrowIt.sln
dotnet test GrowIt.sln        # needs the docker Postgres running

cd mobile
pnpm typecheck
pnpm test                     # node:test, src/**/*.test.ts
```

The integration tests use their own database (`growit_test` on the same server, migrated on
first use; override with `GROWIT_TEST_DB`) and a fake auth handler instead of Cognito. The
mobile tests run the real query client, write queue and axios interceptors under node, with
native modules stubbed in `mobile/test/stubs`.
